# Constraints
* [utf8proc 2.11.3 C API surface](utf8proc-2.11-3-api.md) - utf8proc_NFKD() is a FUNCTION (normalize string), not an option constant. Option constants: UTF8PROC_COMPAT, UTF8PROC_DECOMPOSE, UTF8PROC_CASEFOLD, UTF8PROC_STRIPMARK (enum utf8proc_option_t, scoped-needs-cast). NFKD decomposition via utf8proc_decompose(str, len, buffer, bufsize, UTF8PROC_COMPAT|UTF8PROC_DECOMPOSE|UTF8PROC_CASEFOLD|UTF8PROC_STRIPMARK) returning int32 codepoint array. Output buffer from utf8proc_map freed with std::free, not utf8proc_free (does not exist). utf8proc_int32_t typedef for codepoints.
* [sol2 3.5.0 rejects Lua 5.5 from Arch pacman](sol2-lua-version.md) - sol2 3.5.0 compat header rejects Lua 5.5 (LUA_ERRGCMM undeclared). Since 2026-11-15 both sol2 and lua come from xrepo: sol2 3.5.0 with configs={includes_lua=false}, lua pinned 5.4.8 because bare xrepo 'lua' resolves to 5.5
* [xmake pkg-install interrupted leaves empty hash-dirs](xmake-install-interrupt.md) - Killing xmake during package install (timeout or Ctrl-C) leaves EMPTY hash-dirs under ~/.xmake/packages/<pkg>/<version>/<hash>/. Compile then runs with missing -I and fails on random headers; project config cache (.xmine) keeps stale pkg paths. Recovery: rm -rf ~/.xmake/packages ~/.xmake/cache/packages, then xmake f -c -y (clean reconfig re-resolves+reinstalls). Never kill xmake during its install phase.
* [re2 xrepo version pin](xmake-re2-pin.md) - re2 on xrepo only offers git snapshot versions (git:2025.07.17, git:2025.08.12, git:2025.11.05) plus abseil transitive dep; pinned re2 2025.11.05 in xmake-requires.lock. No numbered release versions available.
* [xmake test runs releasedbg; hand-run release test binaries go stale](test-binary-releasedbg-vs-release.md) - xmake test always executes build/linux/x86_64/releasedbg/test_*; the release/ tree is only rebuilt by an explicit release-mode build, so hand-running release test binaries validates stale code and produces phantom passes/failures.
* [Plugin chapter numbers are untrusted: order, duplicates and placeholder 0](plugin-chapter-number-placeholders.md) - Plugin chapter lists arrive in arbitrary order and may carry duplicate or placeholder numbers (0) or non-numeric upstream numbers; /api/pages resolves prev/next by nearest value, and each plugin's parser needs a name-based fallback.
* [Plugin status strings: canonical vocab, normalized in-plugin](plugin-status-canonical-vocab.md) - Every plugin normalizes its site's status soup to Ongoing/Completed/Hiatus/Dropped/Upcoming (else lowercase alnum passthrough, empty->unknown) before emit; host never per-site normalizes.
* [Chapter state keys: one canonical (decoded) key space; rollup owns total_ch](host-chapter-state-keys.md) - Host state routes percent-decode path ids before keying plugin_state, and apply_read_rollup refreshes total_ch on every path - row-served opens never sync, so totals live or die by the rollup.
* [host.http.fetch* writes body only on HTTP 200 (wasm imports)](host-http-fetch-200-only.md) - src/plugin/wasm/wasm_imports.cpp http_fetch_body/json_fetch only write to the guest buffer when the host reply has status == 200; every other status collapses to kNotFound and the guest sees a silent failure, never a code.
* [Lua host tools require the clang toolchain](lua-host-tools-require-clang.md) - Build with clang only: GCC renders every same-signature lambda to one type name and sol2 3.5.0 keys functor metatables on that name (upstream #1743), so a GCC build dispatches wrong destructors at lua_close and segfaults on plugin teardown / /plugins/reload.
* [host.text.trim / strip_html preserve casing](host-text-trim-preserves-casing.md) - host.text.trim strips only leading/trailing whitespace and control codepoints; it must not casefold, and strip_html keeps text casing. Plugins must not rely on trim to normalize status strings.
* [Plugin page-image regexes must match every image extension a site serves](plugin-image-url-regex.md) - A page-image regex pinned to one extension silently returns zero pages; en-thunderscan matched only .webp while the site serves .jpg.
* [DLE sites: JSON numeric ids must be formatted integrally, and image CDNs need the trailing-slash Referer](dle-json-float-ids.md) - Lua JSON decodes site ids as floats, so tostring renders /reader/15840.0/991476.0 and mangabay's reader 404s (host surfaces it as 'unknown chapter'); komacdn additionally 403s without Referer https://manga-bay.biz/.
