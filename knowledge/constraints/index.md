# Constraints
* [utf8proc 2.11.3 C API surface](utf8proc-2.11-3-api.md) - utf8proc_NFKD() is a FUNCTION (normalize string), not an option constant. Option constants: UTF8PROC_COMPAT, UTF8PROC_DECOMPOSE, UTF8PROC_CASEFOLD, UTF8PROC_STRIPMARK (enum utf8proc_option_t, scoped-needs-cast). NFKD decomposition via utf8proc_decompose(str, len, buffer, bufsize, UTF8PROC_COMPAT|UTF8PROC_DECOMPOSE|UTF8PROC_CASEFOLD|UTF8PROC_STRIPMARK) returning int32 codepoint array. Output buffer from utf8proc_map freed with std::free, not utf8proc_free (does not exist). utf8proc_int32_t typedef for codepoints.
* [sol2 3.5.0 rejects Lua 5.5 from Arch pacman](sol2-lua-version.md) - Arch system lua is 5.5.1; sol2 3.5.0 compat header rejects Lua versions other than 5.1-5.4 (LUA_ERRGCMM undeclared). Fix: keep system lua54 5.4.9 via pkgconfig::lua54, and pull sol2 from xrepo with configs={includes_lua=false} so sol2's recipe does not pull xrepo 'lua' (which resolves to pacman lua 5.5). Do NOT add_requires bare 'lua' from xrepo without system=false or it resolves to pacman 5.5.
* [xmake pkg-install interrupted leaves empty hash-dirs](xmake-install-interrupt.md) - Killing xmake during package install (timeout or Ctrl-C) leaves EMPTY hash-dirs under ~/.xmake/packages/<pkg>/<version>/<hash>/. Compile then runs with missing -I and fails on random headers; project config cache (.xmine) keeps stale pkg paths. Recovery: rm -rf ~/.xmake/packages ~/.xmake/cache/packages, then xmake f -c -y (clean reconfig re-resolves+reinstalls). Never kill xmake during its install phase.
* [re2 xrepo version pin](xmake-re2-pin.md) - re2 on xrepo only offers git snapshot versions (git:2025.07.17, git:2025.08.12, git:2025.11.05) plus abseil transitive dep; pinned re2 2025.11.05 in xmake-requires.lock. No numbered release versions available.
