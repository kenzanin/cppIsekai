* [cppIsekai core architecture: plugin-per-site manga viewer](manga-viewer-core.md) - Plugin-per-site manga viewer: plugins parse HTML themselves, host = crow+mustache + libsql + impersonate proxy w/ disk cache; light sandbox; zero new deps
* [Home demo: library grid, plugin filter, live log](home-demo.md) - Home demo live: partial layouts, htmx grid swaps, Crow built-in /static, PORT env; no mustache inheritance in crow
* [Store migrated to sqlite_orm (Pimpl)](store-orm-migration.md) - Store on sqlite_orm 1.9.1 behind Pimpl, API unchanged; five handoff-vs-header deltas recorded; on_db deadlock fixed; LIKE escaping preserved and verified
* [Library page design (status, progress, done/new badges)](library-page.md) - Design locked: title-level status/total/read/has_update, badges done/new, sidebar filter, mark_read+clear_update, placeholder covers; implementation deferred to user-driven openspec
* [Detail page design + enrichment plugin (alt cover/alt info)](detail-page.md) - Detail page: cover/synopsis/artist/author/tags/chapters + hide-cover (blur/dim) + alt cover & alt info via separate enrichment plugins (mangadex/mangaupdates); lazy fetch cached in title_meta, persisted selection, auto-match with candidates
* [Search & duplicate detection: FTS5 + BM25](fts5-search-dedup.md) - Manga search + duplicate detection via FTS5 + BM25 on the libsql amalgamation; replaces LIKE search; duplicate candidates ranked by BM25 similarity
* [Normalisation contract: MangaDex canonical + chapter release_at](normalization-contract.md) - Host accepts only unix-time integers; JSONB hybrid policy probed on libsql 3.47: jsonb_* family present, filtered data stays columns, variant metadata in slim JSON columns
* [Plugin system: folder packaging, manifest, multi-runtime data-contract ABI](plugin-system.md) - Plugin packaging: one folder per plugin under data/plugins (entry + manifest json + logo), declared via ini; ABI = JSON-text-in/out data contract + per-runtime host-tool bindings; jsonb is DB-side storage only, never the wire format; lua first, wasm/js/micropython later
* [cppIsekai image-cache + offline-first pathway](image-cache-offline.md) - cppIsekai image-cache + offline-first pathway -- cache-layout sub-change COMPLETE 2026-11-08 (9/9 tasks, openspec all_done, ctest 10/10 green, live smoke verified legacy purge + CBZ export).
* [cli-config: registry-backed config surface (CLI/env/ini/dump/save)](cli-config.md) - Decision: config registry single-source di src/config/ (10 knob: flag kebab + CPPISEKAI_* env + ini key + doc) dengan precedence default<ini<env<flag, --config required (help/dump exempt, exit 2 tanpa boot), --dump-config template ber-komentar dari registry, POST /config comment-safe merge (SimpleIni), [paths] menggantikan hardcoded data paths.
* [manga-detail-page: stale-serve + fail-safe refresh pattern](manga-detail-page.md) - Detail page pattern: stale-serve detail/chapters via existing call_cached, fail-safe POST refresh that overwrites both stale entries only after both envelopes validate, SSR shell + Alpine hydrate, per-chapter CBZ links, slug guard 404.
