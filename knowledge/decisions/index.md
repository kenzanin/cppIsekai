# Decisions
* [Build system: CMake + C++23, exe-only](build-toolchain-cpp23.md) - Single executable target, C++23, cmake floor 3.20; lib/tests follow once the first module lands.
* [Dependency vendoring: system-shared first, minimal vendoring](third-party-dependencies.md) - Third-party dependency surface after xmake xrepo migration round 2
* [Plugin data segregation: host .ini is host-only](plugin-data-segregation.md) - Where plugin data lives: host .ini is host-only config; static manifest in main.json; user credentials in gitignored config.json; dynamic state (OAuth tokens) via per-plugin storage host tool backed by the DB.
* [Plugin dev layout: plugins_dev/<lang>/<site> + symlink deploy](plugin-dev-layout.md) - Plugin development happens in plugins_dev/<lang>/<site>/; testing symlinks/copies the plugin into data/plugins/; host ini carries no plugin sections.
* [Dependencies & plugins: curl-first APIs, runtime parity, no hand-rolled crypto](deps-and-plugins.md) - User-confirmed 2026-11-07: curl-first REST routes (CBZ export = host route), plugin runtime parity same signature (quickjs-ng second runtime), no hand-rolled crypto (stbrumme/hash-library md5/sha1), base64 dari glaze, libzippp + pacman libzip, quickjs-ng vendored static.
* [Plugin runtimes: wasm3 + quickjs-ng execution contract](plugin-runtimes-wasm-js.md) - plugin-helper landed: unified host.* namespace (11 tools) across lua/js/wasm, RE2 + lexbor heavy helpers behind one htmltext core, lua fs.read parity closed; lexbor vendor pitfalls (ports/posix memory.c, separate selectors/ subtree) recorded.
* [Fetch profile gate: centralized curl-impersonate, dynamic per-call profile](fetch-profile-gate.md) - User steer 2026-11-08: move the impersonate gate to src/fetch/ (single call site); per-call profile from plugin opts > fetch_profile ini; live default via POST /config; linked-lib targets chrome99-116/edge99-101/safari15; firefox = phase 1 via dual-.so dlopen vtable (steer 2026-11-08); hand-rolled JA3 profile-class rejected.
* [Plugin cookie jars: libcurl-native, per-plugin file state](plugin-cookie-jars.md) - User approved 2026-11-08: native libcurl cookie engine (CURLOPT_COOKIEFILE/JAR), one jar per plugin at data/plugin-state/<id>.cookies.txt, enabled via a fetch-gate option; no new dependencies; implementation lands in change fetch-gate.
* [Search results read-model: JSONB cache via call_cached](search-read-model-cache.md) - User approved 2026-11-08: plugin search results become a JSONB read model in sqlite (search_cache: query_hash, params, results, fetched_at, ttl_s) via opt-in call_cached; fresh = SELECT, no HTTP; the file cache stays; implementation via change search-cache.
* [Source layout: crown facades, ~200-loc units, clang-doc comments](source-layout-policy.md) - Change source-split-clangdoc: crown files become thin facades; logic lives in units of ~200 code-loc or less under src/plugin/{lua,wasm,js} and src/http/{http_pages,http_api}; runtime seams per-folder; public doc-comments clang-doc with why-notes as //; config.hpp (185) and cache.cpp (177) stay unsplit sub-200; audit table in the change codeloc-final.txt.
* [chapter-list-controls: read-state routes and detail rows](chapter-list-controls.md) - Read progress per chapter lives under plugin_state key host/read/<chapter-id> (max pages read; 0 = cleared). Routes: POST /chapter/<id>/read {page}, POST /chapter/state {ids:[...]} -> {<id>: {skip, read}} (absent = unset). POST /reader/position also bumps host/read/<ch> via max(stored, page). Detail page rows carry eye/skip + read toggles and a 20/page client pager rendering [< 1 2 3 ... p-1 p p+1 ... max-2 max-1 max >] (0 marks ellipsis). Alpine x-for pitfalls: keys must NOT reference $index (throws ReferenceError, whole window silently renders nothing), and x-for requires exactly ONE root element — the span+button pair silently rendered only the hidden ellipsis span, leaving just ‹ ›. Fix: single <button> root that renders '…' disabled when n===0. Top pager one line with Chapters heading (flex flex-nowrap whitespace-nowrap, justify-between); bottom pager justify-end. Commit 1b6bd9b; fix 2026-11-11 (x2).
* [cache stale-hit guard: wipe no longer serves 200-blank](cache-stale-hit-guard.md) - Manual cache wipe left the boot-scan index stale; img_ensure hit paths returned deleted paths -> 200-blank images, never refetched. Fix: fs::exists guard on all three hit paths (page ctx, sha fallback, cover_serve); stale entry dropped, falls through to fetch_, re-lands same v3 path. Offline-first preserved: present file never refetches (one stat per hit). Transcode-empty body no longer persists. alive() must run outside mu_ (std::mutex non-recursive): candidate chosen under lock, verified outside. Debug logs on all miss/failure paths. Locked by test_cache 'stale index entry after manual wipe falls through to refetch'. Commit bdd4d9f.
* [browser smoke tooling: blueprint-mcp free mode](browser-smoke-tooling.md) - Live smoke di cppIsekai dipakai via blueprint-mcp FREE mode: call enable dengan {client_id:"free", force_free:true} (tanpa 5555/client_id asli), lalu browser_tabs attach ke tab cppIsekai (daemon tidak selalu jalan di port yang sama; cek `ss -ltn` / pgrep). chrome-cdp butuh remote debugging manual (chrome://inspect/#remote-debugging) dan biasanya tidak aktif. js di browser_evaluate: hindari IIFE/arrow chain berurutan (parser error) — pakai var + statement terpisah. Console messages penuh noise ekstensi (TOTP/content script) + warning Tailwind CDN, abaikan. Related section detail-enrichment adalah text-only title links (sesuai spec), bukan cover grid. Commit 42b5047/97b4cef.
* [search-cache: api read model as JSONB in sqlite](search-cache-jsonb.md) - search-cache (2026-11-10, branch search-cache, commit cd5d515): api read model dipindah ke sqlite JSONB binary — tabel api_cache(plugin_id, query_hash PK, params_json, payload BLOB, fetched_at, ttl_s), payload via jsonb(?)/json(payload) lewat raw sqlite3_* DI DALAM src/store/ saja (sqlite_orm tidak punya JSONB mapping). call_cached kini look-aside fresh (tanpa plugin call, tanpa cached flag), write-through upsert kApiCacheTtl=24h, failure -> last-good + cached:true; kApiCacheTtl ponytail knob. File pool data/cache/api DIHAPUS (boot scan/LRU/purge img-only); .bin dropped tidak dimigrasi. /api/refresh memakai stale_key+api_cache_put. Live probe :8090 /api/detail 2x ok, row JSONB masuk. ctest 14/14, specs 15/15. Menggantikan decisions/search-read-model-cache.
* [dummy seed plugins removed](dummy-seed-removal.md) - Dummy seed plugins (Asura/Flame/Reaper/Void, 4x12 titles) dihapus sepenuhnya (2026-11-10, commits e0ec8f6/3a550c5): block seed di Store ctor dihapus; tests/test_store.cpp pakai fixture raw SQL sendiri (Asura/Flame 2x12, wipe-then-insert, file test_store.db dihapus di dtor); data/library.db dibersihkan (48 titles + 4 plugin rows, backup di /tmp/library.db.bak-*; MangaDex satu-satunya plugin tersisa); spec plugins-page scenario count-click dibuat generic. ctest 14/14 hijau, specs 16/16 valid, daemon :8090 healthy. Plugin nyata ke depan lewat plugins_dev/ + load_all, bukan seed.
* [api_cache NULL payload served as 200-empty-body](api-cache-null-payload.md) - Bug (2026-11-10): detail page /view/manga/<plugin>/<slug> munjuk SyntaxError Unexpected end of JSON input. Akar: 3 row api_cache punya payload NULL (ditulis sebelum jalur jsonb() terbukti kerja); look-aside anggap row fresh -> return body kosong -> HTTP 200 0B -> alpine res.json() throw. Locked by test_store 'api_cache NULL/empty payload is a miss, not a fresh hit' (raw SQL insert NULL row, get returns nullopt). 3 row rusak di data/library.db dihapus; daemon restart :8090, tab detail direload normal. ctest 14/14 hijau. Commit 52f61cd (+ test).
* [reader: chapter 0 is valid — falsy-zero regression fixed + unit-locked](chapter-zero-falsy-regression.md) - Chapter 0 (prequel) and fractional chapters (1.5) were dropped by JS/C++ truthiness checks on 0. * [Settings restart button + per-chapter CBZ cache-full gate](restart-and-cbz-gate.md) - Restart-settings-button via fork watchdog + execv, and per-chapter CBZ gate on cache-full probe.
* [curl-impersonate: chrome-family only; ini-fed profile dropdown; local-time crow log](curl-impersonate-chrome-only.md) - ff* is unsupported in-process (NSS vs BoringSSL fault in curl_multi_perform); chrome-family only, dynamic per request; settings profile dropdown fed from ini fetch_profiles; crow logs in local time.
* [Static assets: vendored, precompressed brotli-only via explicit routes](static-assets-br.md) - Vendored JS ships as precomputed .br via explicit crow routes with year-immutable caching; CDN runtime and plain siblings dropped, brotli treated as universal.
* [Golden-file render test for top-level templates](template-golden-test.md) - Top-level mustache pages are locked by golden-file render tests that catch broken partial includes and dropped context keys.
* [plugin manifest website field -> api rows + card link](plugin-website-field.md) - Optional `website` field in plugin main.json manifest flows to /api/plugins + /api/enrichment rows and renders as an external-link glyph on plugin cards; absent means no link.
* [host.url_encode/url_decode: percent-codec host tool (no crypto yet)](host-url-codec.md) - host.url_encode / host.url_decode added to the Lua plugin ABI: RFC 3986 percent-codec with '+'->space decode; no crypto added (YAGNI — real crypto host tools only when a plugin needs them).
* [api_cache db-lock treated as cache miss: local-first regression (mitigated)](api-cache-lock-miss-regression.md) - db-lock on api_cache_get was indistinguishable from a cache miss -> call_cached fetched despite a cached row; MITIGATED 2026-11-11 by busy_timeout 3s on ORM + raw opens (1b63e59); unknown-title half was valid_title_pair lowercase-only charset (fixed 4091b5c).
* [DB read-parallel deferred: keep single-writer db_pool; read-only scans on demand](db-read-parallel.md) - DB concurrency decision (2026-11-11, deferred): all reads/writes ride db_pool=1 thread today (sqlite_orm storage_t not thread-safe; single ORM connection). Proposed: option 3 — heavy read-only scans (e.g. library dedup FTS5) open SQLITE_OPEN_READONLY raw connections on demand instead of refactoring Store into a connection pool. Full read-parallel option 1 (N reader conns + 1 writer, WAL multi-reader/single-writer) is the harder path and explicitly deferred per user; revisit if grid/dedup queries become hot. Write path stays single-writer always.
* [xmake build system alongside cmake + prod-code gate tasks](xmake-build-system.md) - xmake is the primary build path (cmake kept, ./build rebuilt by xmake). Daily: xmake -j → xmake test; gate = format/fix/build/test with tidy/fix diff-scoped vs HEAD since 2026-11-12 (5a41afc) — vendor-template TUs skip the crawl; always build+test after fix, its reflow has eaten separators. Original decisions d019d91/3a8a466/12b7202.
* [LuaJIT migration: skipped (not faster, higher risk)](luajit-migration.md) - LuaJIT migration considered and explicitly skipped: speed barely improves, cost is build-wiring churn; host crypto via openspec chosen instead.
* [Plugin backends stay struct+dispatch; introduce PluginBackend interface only for a 4th runtime or out-of-process](plugin-backend-interface.md) - Plugin backends stay a struct with concurrent runtime members plus dispatch in Host::call; introduce a polymorphic PluginBackend only when adding a 4th runtime or going out-of-process.
* [Plugin port to JS and WASM — plan](plugin-port-js-wasm.md) - Plan to port cppIsekai plugins to the JS (quickjs) and WASM (wasm3) runtimes from the goIsekai corpus, to expose each runtime's host-tool gaps explicitly.
* [Plugin lifecycle: disabled = cache-only reads; folder-removal GC purges every trace](plugin-lifecycle.md) - Disabled plugin = cache-only reads via a single call_cached gate, quiet scheduler/manual/UI, and folder-removal GC that purges registry + child traces in one transaction per plugin (change plugin-lifecycle, commit 5a41afc).
* [Second xrepo round: pkgconfig deps + utf8proc NFKD tokenizer](xrepo-round-2-deps.md) - Migrated lua (pkgconfig::lua54 system), re2, spdlog, zlib, sqlite3 to xrepo (re2 pinned 2025.11.05, lua forced system because Arch pacman lua is 5.5 incompatible with sol2 3.5.0). Added utf8proc 2.11.3 for Unicode NFKD tokenisation replacing hand-rolled Latin-only fold. All pins locked in xmake-requires.lock. 17/17 tests green.
