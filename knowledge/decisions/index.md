# Decisions
* [Build system: CMake + C++23, exe-only](build-toolchain-cpp23.md) - Single executable target, C++23, cmake floor 3.20; lib/tests follow once the first module lands.
* [Dependency vendoring: system-shared first, minimal vendoring](third-party-dependencies.md) - Dependencies: crow/asio/libvips/lua54/curl-headers/cli11 from pacman; sol2, BS::thread_pool, readerwriterqueue, glaze, wasm3, libsql amalgamation, curl-impersonate and simpleini vendored minimal; pin hashes in README
* [Plugin data segregation: host .ini is host-only](plugin-data-segregation.md) - Where plugin data lives: host .ini is host-only config; static manifest in main.json; user credentials in gitignored config.json; dynamic state (OAuth tokens) via per-plugin storage host tool backed by the DB.
* [Plugin dev layout: plugins_dev/<lang>/<site> + symlink deploy](plugin-dev-layout.md) - Plugin development happens in plugins_dev/<lang>/<site>/; testing symlinks/copies the plugin into data/plugins/; host ini carries no plugin sections.
* [Dependencies & plugins: curl-first APIs, runtime parity, no hand-rolled crypto](deps-and-plugins.md) - User-confirmed 2026-11-07: curl-first REST routes (CBZ export = host route), plugin runtime parity same signature (quickjs-ng second runtime), no hand-rolled crypto (stbrumme/hash-library md5/sha1), base64 dari glaze, libzippp + pacman libzip, quickjs-ng vendored static.
* [Plugin runtimes: wasm3 + quickjs-ng execution contract](plugin-runtimes-wasm-js.md) - Change plugin-js-wasm 9/9: dual runtime (wasm3 ABI + quickjs realm) behind ONE shared shape/health core; parity host tools; confined fs.read; gas/interrupt budgets; hardening lessons (JS refcount consume, per-invoke stack rebase, glz brace-init).
* [Fetch profile gate: centralized curl-impersonate, dynamic per-call profile](fetch-profile-gate.md) - User steer 2026-11-08: gate impersonate pindah ke src/fetch/ (satu-satunya call site), profile per-call dari opts plugin > fetch_profile ini, default live via POST /config; targets lib ter-link chrome99-116/edge99-101/safari15; firefox = phase 2 (.so terpisah); menolak profile-class JA3 hand-rolled.
* [Plugin cookie jars: libcurl-native, per-plugin file state](plugin-cookie-jars.md) - User approve 2026-11-08: cookie engine native libcurl (CURLOPT_COOKIEFILE/JAR), satu jar per plugin di data/plugin-state/<id>.cookies.txt, diaktifkan lewat opsi fetch gate; tanpa dependensi baru; implementasi menyusul di change fetch-gate.
* [Search results read-model: JSONB cache via call_cached](search-read-model-cache.md) - User approve 2026-11-08: hasil search plugin jadi read-model JSONB di sqlite (search_cache: query_hash, params, results, fetched_at, ttl_s) lewat call_cached opt-in; fresh = SELECT tanpa HTTP; file-cache stale tetap; implementasi via change search-cache.
