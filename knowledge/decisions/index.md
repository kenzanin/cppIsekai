# Decisions
* [Build system: CMake + C++23, exe-only](build-toolchain-cpp23.md) - Single executable target, C++23, cmake floor 3.20; lib/tests follow once the first module lands.
* [Dependency vendoring: system-shared first, minimal vendoring](third-party-dependencies.md) - Dependencies: crow/asio/libvips/lua54/curl-headers/cli11 from pacman; sol2, BS::thread_pool, readerwriterqueue, glaze, wasm3, libsql amalgamation, curl-impersonate and simpleini vendored minimal; pin hashes in README
* [Plugin data segregation: host .ini is host-only](plugin-data-segregation.md) - Where plugin data lives: host .ini is host-only config; static manifest in main.json; user credentials in gitignored config.json; dynamic state (OAuth tokens) via per-plugin storage host tool backed by the DB.
* [Plugin dev layout: plugins_dev/<lang>/<site> + symlink deploy](plugin-dev-layout.md) - Plugin development happens in plugins_dev/<lang>/<site>/; testing symlinks/copies the plugin into data/plugins/; host ini carries no plugin sections.
* [Dependencies & plugins: curl-first APIs, runtime parity, no hand-rolled crypto](deps-and-plugins.md) - User-confirmed 2026-11-07: curl-first REST routes (CBZ export = host route), plugin runtime parity same signature (quickjs-ng second runtime), no hand-rolled crypto (stbrumme/hash-library md5/sha1), base64 dari glaze, libzippp + pacman libzip, quickjs-ng vendored static.
* [Plugin runtimes: wasm3 + quickjs-ng execution contract](plugin-runtimes-wasm-js.md) - plugin-helper landed: unified host.* namespace (11 tools) across lua/js/wasm, RE2 + lexbor heavy helpers behind one htmltext core, lua fs.read parity closed; lexbor vendor pitfalls (ports/posix memory.c, separate selectors/ subtree) recorded.
* [Fetch profile gate: centralized curl-impersonate, dynamic per-call profile](fetch-profile-gate.md) - User steer 2026-11-08: move the impersonate gate to src/fetch/ (single call site); per-call profile from plugin opts > fetch_profile ini; live default via POST /config; linked-lib targets chrome99-116/edge99-101/safari15; firefox = phase 1 via dual-.so dlopen vtable (steer 2026-11-08); hand-rolled JA3 profile-class rejected.
* [Plugin cookie jars: libcurl-native, per-plugin file state](plugin-cookie-jars.md) - User approved 2026-11-08: native libcurl cookie engine (CURLOPT_COOKIEFILE/JAR), one jar per plugin at data/plugin-state/<id>.cookies.txt, enabled via a fetch-gate option; no new dependencies; implementation lands in change fetch-gate.
* [Search results read-model: JSONB cache via call_cached](search-read-model-cache.md) - User approved 2026-11-08: plugin search results become a JSONB read model in sqlite (search_cache: query_hash, params, results, fetched_at, ttl_s) via opt-in call_cached; fresh = SELECT, no HTTP; the file cache stays; implementation via change search-cache.
* [Source layout: crown facades, ~200-loc units, clang-doc comments](source-layout-policy.md) - Change source-split-clangdoc: crown files become thin facades; logic lives in units of ~200 code-loc or less under src/plugin/{lua,wasm,js} and src/http/{http_pages,http_api}; runtime seams per-folder; public doc-comments clang-doc with why-notes as //; config.hpp (185) and cache.cpp (177) stay unsplit sub-200; audit table in the change codeloc-final.txt.
* [chapter-list-controls: read-state routes and detail rows](chapter-list-controls.md) - Read progress per chapter lives under plugin_state key host/read/<chapter-id> (max pages read; 0 = cleared). Routes: POST /chapter/<id>/read {page}, POST /chapter/state {ids:[...]} -> {<id>: {skip, read}} (absent = unset). POST /reader/position also bumps host/read/<ch> via max(stored, page). Detail page rows carry eye (read) + double-check (done/skip) toggles and a 20/page client pager. Commit 1b6bd9b.
* [cache stale-hit guard: wipe no longer serves 200-blank](cache-stale-hit-guard.md) - Manual cache wipe left the boot-scan index stale; img_ensure hit paths returned deleted paths -> 200-blank images, never refetched. Fix: fs::exists guard on all three hit paths (page ctx, sha fallback, cover_serve); stale entry dropped, falls through to fetch_, re-lands same v3 path. Offline-first preserved: present file never refetches (one stat per hit). Transcode-empty body no longer persists. alive() must run outside mu_ (std::mutex non-recursive): candidate chosen under lock, verified outside. Debug logs on all miss/failure paths. Locked by test_cache 'stale index entry after manual wipe falls through to refetch'. Commit bdd4d9f.
* [browser smoke tooling: blueprint-mcp free mode](browser-smoke-tooling.md) - Live smoke di cppIsekai dipakai via blueprint-mcp FREE mode: call enable dengan {client_id:"free", force_free:true} (tanpa 5555/client_id asli), lalu browser_tabs attach ke tab cppIsekai (daemon tidak selalu jalan di port yang sama; cek `ss -ltn` / pgrep). chrome-cdp butuh remote debugging manual (chrome://inspect/#remote-debugging) dan biasanya tidak aktif. js di browser_evaluate: hindari IIFE/arrow chain berurutan (parser error) — pakai var + statement terpisah. Console messages penuh noise ekstensi (TOTP/content script) + warning Tailwind CDN, abaikan. Related section detail-enrichment adalah text-only title links (sesuai spec), bukan cover grid. Commit 42b5047/97b4cef.
* [search-cache: api read model as JSONB in sqlite](search-cache-jsonb.md) - search-cache (2026-11-10, branch search-cache, commit cd5d515): api read model dipindah ke sqlite JSONB binary — tabel api_cache(plugin_id, query_hash PK, params_json, payload BLOB, fetched_at, ttl_s), payload via jsonb(?)/json(payload) lewat raw sqlite3_* DI DALAM src/store/ saja (sqlite_orm tidak punya JSONB mapping). call_cached kini look-aside fresh (tanpa plugin call, tanpa cached flag), write-through upsert kApiCacheTtl=24h, failure -> last-good + cached:true; kApiCacheTtl ponytail knob. File pool data/cache/api DIHAPUS (boot scan/LRU/purge img-only); .bin dropped tidak dimigrasi. /api/refresh memakai stale_key+api_cache_put. Live probe :8090 /api/detail 2x ok, row JSONB masuk. ctest 14/14, specs 15/15. Menggantikan decisions/search-read-model-cache.
* [dummy seed plugins removed](dummy-seed-removal.md) - Dummy seed plugins (Asura/Flame/Reaper/Void, 4x12 titles) dihapus sepenuhnya (2026-11-10, commits e0ec8f6/3a550c5): block seed di Store ctor dihapus; tests/test_store.cpp pakai fixture raw SQL sendiri (Asura/Flame 2x12, wipe-then-insert, file test_store.db dihapus di dtor); data/library.db dibersihkan (48 titles + 4 plugin rows, backup di /tmp/library.db.bak-*; MangaDex satu-satunya plugin tersisa); spec plugins-page scenario count-click dibuat generic. ctest 14/14 hijau, specs 16/16 valid, daemon :8090 healthy. Plugin nyata ke depan lewat plugins_dev/ + load_all, bukan seed.
* [api_cache NULL payload served as 200-empty-body](api-cache-null-payload.md) - Bug (2026-11-10): detail page /view/manga/<plugin>/<slug> munjuk SyntaxError Unexpected end of JSON input. Locked by test_store 'api_cache NULL/empty payload is a miss, not a fresh hit' (raw SQL insert NULL row, get returns nullopt). 3 row rusak di data/library.db dihapus; daemon restart :8090, tab detail direload normal. ctest 14/14 hijau. Commit 52f61cd (+ test).
