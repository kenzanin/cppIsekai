* [Search results read-model: JSONB cache via call_cached](search-read-model-cache.md) - User approved 2026-11-08: plugin results as a JSONB read model via opt-in call_cached; TTL policy extended 2026-11-18 (d423b11): per-method host default + per-plugin manifest cache_ttl override.

Commit 1b6bd9b; fix 2026-11-11 (x2).
