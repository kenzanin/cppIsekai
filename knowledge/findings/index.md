* [xmake cxx_bin: def-time add_ldflags can drop flags; on_load t:add is the reliable route](xmake-ldflags-on-load-hook.md) - In the shared cxx_bin helper, flags added via def-time add_ldflags(..., {force=true}) can silently miss the link command (-rdynamic was dropped while CURL_SO from the very same call landed); the proven route is t:add('ldflags', ..., {force=true}) inside the target on_load hook, the same path that injects -fuse-ld=mold.
