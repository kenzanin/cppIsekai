* [Detail vs library title mismatch: fixed (glaze map insert invalidated the title view)](detail-name-vs-library-card.md) - Detail h1 was empty ('…') while the library card showed a title. Root cause was NOT the api_cache jsonb/ok theory recorded on 2026-11-15: json_type(payload,'$.ok') is 'true' and json(payload) emits literal true, so envelope_ok always passed. The real bug was inside apply_chosen's ensure_name() (src/http/enrich_internal.hpp): 'd["name"].data = *s' assigned through a reference into the SAME glaze object, and glaze's object_t is a flat map (ordered_small_map) whose insertion of "name" relocates the title node -- the assignment then read moved memory and wrote an empty name (live /api/detail showed "name":""). Fixed by copying the title into a local std::string first; regression test 'apply_chosen derives detail name from the scraper title' added. Committed 9966ecb.
